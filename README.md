📌 Project Overview

This project involves creating a centered login page using HTML and CSS. The login form is positioned at the center of the webpage with a clean and attractive design.

🎯 Objectives

* Create a login form using HTML.
* Use CSS to style the login page.
* Center the login form horizontally and vertically.
* Style input fields and buttons.
* Practice CSS Flexbox and layout techniques.

🛠️ Technologies Used

* HTML5 – To create the login form structure.
* CSS3 – To style and center the login form.

✨ Features

* Centered login form.
* Username and password input fields.
* Styled login button.
* Clean and user-friendly interface.
* Proper spacing, padding, and alignment.
* Attractive background and form design.

🚀 How to Run

1. Open the project folder in Visual Studio Code.
2. Open index.html using Live Server.
3. View the centered login page in your browser.

📚 Learning Outcomes

Through this assignment, I learned how to create a login form, center elements using CSS Flexbox, style form inputs and buttons, and improve webpage layouts.
